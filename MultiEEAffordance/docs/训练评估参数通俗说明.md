## 训练参数

`sample_size` 表示每个点云采样多少个点进入模型。PointNet 和 PointNeXt 都使用同一个 dataloader，因此输入 shape 是 `[B,N,C]`。

`input_channels` 当前支持 `3` 或 `6`。`3` 表示只用 xyz，`6` 表示 xyz 加额外点特征。

`hidden_dim` 是本项目 task/executor head 的隐藏维度，不等于 PointNeXt 原始 segmentation head 的类别数。

`executor_condition_mode` 控制执行器如何进入模型：

```text
learnable_id: 每个执行器一个可学习 token
one_hot_id: 执行器 one-hot 后映射成 token
attr_only: 只用执行器属性
id_attr: 类别 ID 和属性一起用
id_attr_film: ID+属性，并用属性 FiLM 调节点特征
id_attr_crossattn: ID+属性，并让 executor query 与点特征做简化 cross-attention
```

## Loss 参数

`lambda_dice` 控制 Dice loss 权重，帮助 mask 更关注区域重叠。

`lambda_feasibility` 控制 feasibility 二分类权重。

`lambda_empty_area` 控制不可行执行器的空 mask 约束，避免模型在不可行通道上乱预测大区域。

`lambda_relation` 控制执行器间 mask 重叠关系约束。它适合做消融，不建议在没有对照结果前作为唯一主实验结论。

## 评估参数

`macro_iou` 是所有有监督 task-executor 单元的平均 IoU。

`macro_dice` 是所有有监督 task-executor 单元的平均 Dice。

`macro_feasibility_f1` 衡量模型判断某执行器对某任务是否可行的 F1。

`empty_mask_accuracy` 衡量不可行通道是否被正确预测为空。

`small_part_recall` 用于观察小区域 affordance 是否被漏掉。

`executor_overlap_matrix_error` 用于观察模型是否学到不同执行器 mask 之间的重叠关系。

## 阈值校准

默认评估用 0.5 阈值。校准评估会在 validation split 上为每个 executor 选择 mask threshold 和 feasibility threshold，再在 test split 上评估。

入口：

```text
training/evaluate_calibrated.py
```

建议同时报告：

```text
calibrated + no gate
calibrated + feasibility gate
```

这样可以区分“阈值调好”与“feasibility gating”分别带来的影响。

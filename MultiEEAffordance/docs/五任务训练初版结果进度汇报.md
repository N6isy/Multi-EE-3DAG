## 当前阻塞

`openpoints` 顶层导入已经可以通过，但真实 PointNeXt forward 需要编译 CUDA 扩展：

```text
pointnet2_batch_cuda
```

当前机器没有可用 NVIDIA driver，`nvidia-smi` 失败，也没有 `nvcc`，因此不能在当前环境完成 PointNeXt smoke test 和 debug 训练。

## 下一步

1. 在有 CUDA toolkit 和 NVIDIA driver 的训练机编译 OpenPoints `pointnet2_batch` 扩展。
2. 运行 `smoke_test_backbone.py` 确认 `[B,N,C] -> [B,N,D]` 且无 NaN。
3. 运行 `pointnext_shared4_5tasks_debug.json`，确认 loss 有数值，并保存 `latest.pt / best.pt`。
4. 正式跑 `pointnext_shared4_5tasks.json`。
5. 依次跑 executor attribute 消融，比较 `learnable_id / attr_only / id_attr / id_attr_film / id_attr_crossattn`。

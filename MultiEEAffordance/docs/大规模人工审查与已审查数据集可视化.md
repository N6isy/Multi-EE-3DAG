# 大规模人工审查与已审查数据集可视化

## 当前任务策略

暂时只保留三类任务：

- `pick_up`
- `open_pull`
- `press_push`

`lift_carry` 与 `pick_up` 在当前点云数据和执行器定义下过于接近，后续第一版大规模人工审查默认排除 `lift_carry`。原始数据不删除，只在生成审查队列、v3 pipeline 和 reviewed dataset release 时过滤。

## 1. 生成大规模审查队列

从 `samples_checked_v0_1.jsonl` 展开成 channel-level 队列，每行是一个 `sample_id + task + executor` 审查单元：

```bash
python MultiEEAffordance/tools/build_large_scale_review_queue.py \
  --dataset-root MultiEEAffordance \
  --output-csv processed/metadata/v3_large_scale_review_queue_v0_1.csv \
  --summary-json processed/metadata/v3_large_scale_review_queue_summary_v0_1.json \
  --include-tasks pick_up,open_pull,press_push \
  --exclude-tasks lift_carry \
  --executor-scope feasible \
  --quality-scope needs_review \
  --limit 200 \
  --overwrite
```

如果要生成全量队列，去掉 `--limit`。

## 2. 跑 v3 候选生成 pipeline

用上一步生成的队列作为 `--pilot-csv`：

```bash
CUDA_VISIBLE_DEVICES=1,2 python MultiEEAffordance/tools/run_v3_pipeline.py \
  --dataset-root MultiEEAffordance \
  --config configs/qwen3vl_sam2_pilot.yaml \
  --pilot-csv processed/metadata/v3_large_scale_review_queue_v0_1.csv \
  --include-tasks pick_up,open_pull,press_push \
  --exclude-tasks lift_carry \
  --stages views,plan,ground,project,grow,render,build \
  --allow-empty \
  --overwrite
```

该命令会生成 `processed/metadata/v3_candidate_samples_v0_1.jsonl`，用于进入网页人工审查。

## 3. 启动点级人工审查系统

建议 v3 审查时显式指定 v3 输出路径，避免继续写入 v2 默认文件：

```bash
python MultiEEAffordance/tools/serve_v2_annotation_app.py \
  --dataset-root MultiEEAffordance \
  --samples processed/metadata/v3_candidate_samples_v0_1.jsonl \
  --review-jsonl processed/metadata/v3_point_level_review_records.jsonl \
  --output-mask-root processed/vlm_candidate_v3/manual_refined_masks \
  --output-samples processed/metadata/v3_manual_refined_samples_v0_1.jsonl \
  --port 8765 \
  --top-k-candidates 5 \
  --candidate-min-selected-votes 2
```

审查系统现在使用蓝白主色。左键用圆形 brush 增删点，右键旋转点云，滚轮缩放。

## 4. 打包已审查数据集

人工审查完成后，把 `checked/verified` 样本打包成第一版 reviewed dataset：

```bash
python MultiEEAffordance/tools/build_reviewed_dataset_release.py \
  --dataset-root MultiEEAffordance \
  --reviewed-samples processed/metadata/v3_manual_refined_samples_v0_1.jsonl \
  --output-samples processed/metadata/reviewed_dataset_v0_1.jsonl \
  --summary-json processed/metadata/reviewed_dataset_summary_v0_1.json \
  --output-split-dir splits_reviewed_v0_1 \
  --include-tasks pick_up,open_pull,press_push \
  --exclude-tasks lift_carry \
  --overwrite
```

输出的 `reviewed_dataset_v0_1.jsonl` 只包含人工点级审查通过的样本，不再把自动候选直接视为 GT。

## 5. 启动已审查数据集可视化系统

```bash
python MultiEEAffordance/tools/serve_reviewed_dataset_viewer.py \
  --dataset-root MultiEEAffordance \
  --samples processed/metadata/reviewed_dataset_v0_1.jsonl \
  --port 8780
```

如果还没有打包 release，也可以直接看人工审查输出：

```bash
python MultiEEAffordance/tools/serve_reviewed_dataset_viewer.py \
  --dataset-root MultiEEAffordance \
  --samples processed/metadata/v3_manual_refined_samples_v0_1.jsonl \
  --port 8780
```

可视化系统是只读的，主要用于快速检查已经完成审查的数据集：按样本浏览、查看任务/执行器统计、旋转点云、突出显示目标执行器正样本点。

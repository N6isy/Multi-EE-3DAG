### 失败复盘

- 远程 `vlm_pilot_005: Bag / lift_carry / hook` 实验显示，即使给出候选 overlay 和局部放大图，Qwen3-VL 仍多次输出 `no hookable structure visible`，没有选择包体上方的 handle 候选。

- 初版失败的关键原因不是 Qwen3-VL 不能用于本项目，而是使用方式不合适：
  - 稀疏点云渲染图不像自然图像，VLM 难以稳定识别少量点构成的 handle / loop。
  - 让 Qwen3-VL 直接输出 box / point，本质上是在要求它做非自然图像上的精确像素标注，这是其弱项。

  - 几何候选 A/B/C 可以发现上方结构，但几何规则本身没有 VLM 的语义知识，不能单独承担最终标注判断。
  - 3D AffordanceNet full-shape 没有明确 hook mask，不能通过已有标签直接修复 hook 通道。

### 新判断

VLM 的角色应从“像素坐标标注器”调整为“语义部件规划器”。新版 pipeline 的核心思想是：

```text
VLM 负责识别目标部件和解释任务-执行器机制；
GroundingDINO / Florence-2 负责根据部件文本定位 2D 区域；
SAM2 负责生成 2D mask；
point_index map 负责回投真实 3D 点；
几何规则负责校验；
人工审查负责最终确认。
```

  - 删除模式只删除 `positives` 中的点，因此点击候选预览点时会表现为删不掉；

- 当前修正为：
  - checkbox 勾选/取消时，立即把当前勾选候选的并集同步为可编辑 mask；
  - “应用勾选候选”保留，但本质上是重新应用当前勾选集合；
  - 删除模式下，非正样本点不再显示候选预览颜色，保证删掉的点能立刻从当前 mask 视觉中消失；
  - 页面加载时不再自动用候选预览覆盖当前 mask，避免 refined mask 被候选预览干扰。
